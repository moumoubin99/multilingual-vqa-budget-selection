# Attribution and licensing boundaries

This repository contains original numerical experiment outputs, selected metadata derived from third-party benchmark datasets, and research code. These are different materials with different licensing boundaries.

- WorldCuisines: upstream `worldcuisines/vqa-v1.1`, https://huggingface.co/datasets/worldcuisines/vqa-v1.1, declared CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/). Attribute the dataset authors via the upstream dataset card/paper. The WorldCuisines source IDs, gold indices and selected benchmark metadata retain that attribution and licensing. No dataset images or original question/option/answer text are included here.
- CVQA: upstream `afaji/cvqa`, https://huggingface.co/datasets/afaji/cvqa; paper https://arxiv.org/abs/2406.05967. Its dataset card specifies per-entry/image licensing and research-use restrictions for some entries. This package contains selection/source IDs, numeric gold indices and hashes, without images or question/option/answer text. This package does not grant additional rights in upstream CVQA material. Obtain upstream content directly and follow the relevant source permissions.
- Qwen2.5-VL-3B-Instruct: https://huggingface.co/Qwen/Qwen2.5-VL-3B-Instruct, pinned revision recorded in provenance/model_identity.json. No model weights, adapters, tokenizer files, or upstream package implementations are included. Follow the upstream model/software licenses when obtaining them.
- Original code: copyright Jibin Zhang and Hui Gui. A permissive software license has not been assigned in this staged package; the authors must select a license before licensing original code for reuse. Publication of source here does not purport to license third-party software.
- Original numerical research predictions and aggregate outputs produced by Jibin Zhang and Hui Gui are provided for research checking and statistical reproduction. No additional unified license or rights waiver has been selected for these outputs. Factual numerical research results are distinguished here from third-party gold labels/source metadata and copyrightable code. Third-party gold-label/source fields retain the benchmark licensing boundaries above. The authors may select an explicit code/output license in a future release.

The `code/` files contain experiment implementations and explicitly named external dependencies. They do not embed upstream model implementations. Provenance records containing public package identities do not redistribute those packages.
